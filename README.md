# Manos x Chile

Proyecto Next.js para construir el sitio/app de Manos x Chile usando la base visual incluida en `design-system/`.

## Stack

- Next.js 16.2.9 con App Router
- React 19
- TypeScript
- Tailwind CSS 4
- ESLint 9

## Comandos

```bash
npm run dev
npm run build
npm run lint
```

La app principal vive en `src/app/`. Los assets públicos preparados para la pantalla inicial están en `public/brand/`.
