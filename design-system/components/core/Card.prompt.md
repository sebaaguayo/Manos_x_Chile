Signature container — beveled 24px corners, white surface, optional 3px colored ring (the brand's outlined-card halo) + soft shadow.

```jsx
<Card ring="blue">Outlined in ocean-blue</Card>
<Card ring="green" interactive>Lifts on hover</Card>
<Card>Plain hairline card (ring="none")</Card>
```

Props: `ring` ("blue" | "green" | "none"), `interactive` (hover lift), `fill` ("white" | "soft" | CSS color), `padding`, `radius`.
